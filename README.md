## 🎯 Objetivo do Desafio

Modificar e aprimorar o relatório criado durante as aulas, aplicando os seguintes princípios fundamentais de design de interfaces e visualização de dados:

- 📐 **Posicionamento estratégico** dos elementos visuais.
- 🎨 **Contraste adequado** entre cores e componentes para melhor legibilidade.
- 📏 **Proporção Áurea** na distribuição do layout e organização dos gráficos.
- 🔍 **Segmentação dos dados** de forma intuitiva, utilizando filtros e segmentadores bem posicionados.

## ✅ Requisitos Atendidos

- [x] Botões interativos de navegabilidade entre as páginas do relatório.
- [x] Segunda página (*Report de Lucro Detalhado*) padronizada com a mesma identidade visual e de UX da primeira página.
- [x] Configuração de estados dinâmicos (foco, seleção e *hover*) nos botões de navegação.
- [x] Menu lateral de navegação replicado em todas as páginas para facilitar o uso.
- [x] Estilização e formatação customizada dos botões.

## 🏗️ Estrutura do Relatório

O arquivo `.pbix` foi estruturado em 3 páginas principais para facilitar a análise dos indicadores:

| 📄 Página | 📝 Conteúdo Principal |
| :--- | :--- |
| **1. Sales** | Total de vendas, unidades vendidas, vendas por produto e por período, além de uma tabela sumarizada por trimestres. |
| **2. Report de Lucro Detalhado** | Lucro por produto, lucro por segmento, análise de *drill-down* por país/ano e total de lucros por trimestre. |
| **3. Report de Vendas Detalhado** | Comparativo de *Sales x Gross* por período, tabela detalhada de trimestres e gráfico combinado. |

## 💻 Tecnologias Utilizadas

- ![Power BI](https://img.shields.io/badge/Power_BI-F2C811?style=for-the-badge&logo=powerbi&logoColor=black) **Power BI Desktop**
- 🧮 **DAX** *(Data Analysis Expressions)* para criação de medidas e colunas calculadas.
- 🎛️ **Filtros e Segmentadores** interativos de dados (Ano, País).

## 🚀 Como Visualizar

1. Certifique-se de ter o **[Power BI Desktop](https://powerbi.microsoft.com/desktop/)** instalado em sua máquina.
2. Faça o download do arquivo `.pbix` presente neste repositório.
3. Abra o arquivo no Power BI Desktop.
4. Utilize o menu lateral interativo para navegar fluidamente entre as páginas do relatório.
